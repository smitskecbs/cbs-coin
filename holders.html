How this number works

The holder count is fetched from the Birdeye token API for the CBS mint address. It represents the number of unique wallets that currently hold a non-zero CBS balance.

Different explorers sometimes show slightly different numbers, depending on how they filter dust wallets, frozen accounts, or outdated program accounts. This page simply mirrors Birdeye’s view.

If the API is temporarily rate-limited or offline, the last successful value will stay visible and you can try again with the Refresh now button.

NOTE: If you see “Live data unavailable”, press F12 → Console and send a screenshot of the Birdeye JSON response in Telegram, so we can further fine-tune the parsing.
