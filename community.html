# Owner (wallet) Token balance Naam (claim)
Bron: Solana RPC → getTokenLargestAccounts + getParsedAccountInfo. Geen backend nodig. Voor nu bewaren we namen in localStorage. Later kunnen we overschakelen op een publieke JSON of kleine database.

Uitleg (simpel)

  1. Klik Wallet verbinden (Phantom/oké-keuring).
  2. We halen top token-accounts op voor de CBS Coin mint en tonen de owners.
  3. Als jouw wallet-adres overeenkomt met een owner in de lijst, kun je een naam claimen.
  4. Namen worden lokaal onthouden. Wil je het publiek maken? Dan voegen we later een klein JSON-bestand of webhook toe.
