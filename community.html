# Owner (wallet) Token balance Naam (claim)
Bron: Solana JSON‑RPC (getTokenLargestAccounts → getParsedAccountInfo). Namen worden nu alleen lokaal opgeslagen (localStorage). Later kunnen we dit publiek maken via een JSON-bestand in je repo of een lichte database.

Hoe werkt het?

  1. Klik Wallet verbinden (Phantom vereist).
  2. De pagina haalt de top token‑accounts op voor de CBS Coin mint en toont de owners.
  3. Als jouw wallet gelijk is aan een owner in de tabel, kun je een naam claimen (veld + Opslaan).
  4. Je naam wordt lokaal onthouden. Wil je zichtbaarheid voor iedereen? Gebruik de export en zet het JSON‑bestand publiek, of koppel een kleine webhook.
