CBS Contest Bot

Overview

Telegram bot for a holders-only community contest. Users register a Solana wallet, verify CBS holdings, and submit activity links. This page explains how to use and operate the bot.

This bot polls Telegram (no webhook) and stores data in a local SQLite database.

Overzicht

Telegram-bot voor een contest alleen voor holders. Gebruikers registreren een Solana-wallet, verifiëren hun CBS-bezit en dienen activiteiten in. Deze pagina legt uit hoe je de bot gebruikt en beheert.

De bot gebruikt polling (geen webhook) en slaat data op in een lokale SQLite-database.

User — Quick Start

  1. Send /start in DM to the bot.
  2. Register your wallet: 
    /join <WALLET_ADDRESS>
    Example: 
    /join 8Y7wEBB15f8mpQ7H5Wa1pVdo1TNSg2KE7rLKApHUk5Zd
  3. Verify you hold ≥1 CBS in that wallet: 
    /verify
    You should see holder ✅ if OK.
  4. Submit activity links during the contest window (see /settings).

Submission commands

  • /tx <link|signature> — CBS transfer/tx (+2)
  • /post <x-link> — your CBS-related post (+3)
  • /tx <x-link> — like/retweet of CBS-related post (+1)
  • /meme <url> — meme (rate-limited) (+5)
  • /invite @user — pending until user is holder (+3)
  • /me — your score • /score — leaderboard
  • /ref — referral explanation

Links are strictly validated (domains, format, duplicates) to reduce spam/scams.

Owner — Setup

Requirements

  • Python 3.12+
  • Packages: python-telegram-bot==21.6, APScheduler==3.10.4, pytz, validators, requests
  • SQLite (bundled with Python)

Environment

  • BOT_TOKEN — BotFather token (keep secret) required
  • RPC_URL — Solana RPC (Helius endpoint recommended) required
  • ADMIN_IDS — comma-separated Telegram user IDs (e.g. 11111,22222)

Run locally (foreground)

cd ~/CBSbot2
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export BOT_TOKEN="<YOUR_TOKEN>>"
export RPC_URL="https://mainnet.helius-rpc.com/?api-key=<KEY>"
export ADMIN_IDS="12345,67890"
python bot.py

Run as a systemd service

[Unit]
Description=CBS Telegram bot
After=network.target

[Service]
WorkingDirectory=/home/<user>/CBSbot2
Environment=BOT_TOKEN=<your token>
Environment=RPC_URL=https://mainnet.helius-rpc.com/?api-key=<key>
Environment=ADMIN_IDS=12345,67890
ExecStart=/home/<user>/CBSbot2/.venv/bin/python /home/<user>/CBSbot2/bot.py
Restart=always
RestartSec=5
User=<user>

[Install]
WantedBy=multi-user.target
sudo systemctl daemon-reload
sudo systemctl enable --now cbsbot
sudo journalctl -u cbsbot -n 50 --no-pager

Safety & Anti-Scam

  • Wallet format is validated; only one wallet per user. Duplicate wallets are rejected.
  • Only x.com/twitter.com URLs are accepted for Twitter/X content; other domains are rejected.
  • Each external link/signature counts once (duplicate submissions are ignored).
  • Invite points are pending until the invited user verifies as a holder.
  • Outputs are plain text (no HTML parse in Telegram) to avoid formatting exploits.

Veiligheid & Anti-scam

  • Wallet-formaat wordt gevalideerd; één wallet per gebruiker. Dubbelen worden geweigerd.
  • Alleen x.com/twitter.com links worden geaccepteerd voor Twitter/X-content; andere domeinen worden geweigerd.
  • Elke externe link/signature telt één keer (dubbele inzendingen worden genegeerd).
  • Invite-punten blijven “pending” tot de uitgenodigde user holder is.
  • Uitvoer is platte tekst (geen HTML-opmaak in Telegram) om parsing-fouten/exploits te voorkomen.

Troubleshooting

  • InvalidToken — check BOT_TOKEN in service/env.
  • UNIQUE constraint failed — dedupe the DB, then create a unique index on (type, ref).
  • No holder — ensure the registered wallet holds ≥1 CBS; try /verify again.
  • Logs: 
    sudo journalctl -u cbsbot -n 100 --no-pager

Probleemoplossing

  • InvalidToken — controleer BOT_TOKEN in service/env.
  • UNIQUE constraint failed — dedupe de DB, maak daarna een unieke index op (type, ref).
  • Geen holder — zorg dat de geregistreerde wallet ≥1 CBS bezit; gebruik /verify opnieuw.
  • Logs: 
    sudo journalctl -u cbsbot -n 100 --no-pager
