CBS Bot – Community Helper for Telegram

Use this bot in any Telegram group. All actions via slash commands (no keyword triggers). Features: links, welcome, autochat, antibot, raid mode with counters, invite contest, join-raid detector.

✨ Slash-only (no spam) 📊 Raid counters 🛡️ Antibot & whitelist 🏆 Invite contest 🌐 EN / NL guide

Quick Start (EN)

1.Add @CBS_Coin_bot to your group.
2.In BotFather → Bot Settings: set Allow Groups = ON and Group Privacy = OFF.
3.(Recommended) Make the bot Admin to use Antibot and Invite Links.
4.Set links: /set website <url>, /set twitter <url>, …
5.Optional raid: /set raid on → /raidtarget <url> → /raidtargets 15 5 10 → /raid.
6.Optional contest: /set contest on → users run /mylink → track via /contest.
Slash-only: The bot answers only to /commands (e.g. /x, /website). Plain words like “x” do nothing.

What it does

Highlights

  • 👋 Welcome new members (customizable)
  • 💬 Subtle replies to greetings/thanks/fun max 1 per 30s per chat
  • ✨ Autochat every ~30 min (toggleable)
  • 🛡️ Antibot (block new bots) + whitelist
  • 🚩 Raid mode with Like/Repost/Comment counters
  • 🏆 Invite contest (personal links + leaderboard)
  • 🔗 Group links via slash: /website /twitter /x /telegram /discord /facebook /instagram /youtube /mint /ca /rules

Permissions you need in Telegram

  • Bot must read & send messages (Group Privacy OFF)
  • Antibot: bot needs “Ban users”
  • Invite Contest: bot needs “Invite users via link”

Raid Mode — step by step

Setup

  1. /set raid on
  2. /raidtarget <url>
  3. /raidtargets <likes> <reposts> <comments> (e.g. /raidtargets 15 5 10)
  4. (Optional) /raidmsg <text with {url}>
  5. /raid — post with Like / Repost / Comment buttons

Members can tap each button once; the bot counts unique users per action.

Monitor & control

  • /raidprogress
  • /raidreset
  • /x — show configured X/Twitter link
  • /set raid off — disable raid mode

Join-Raid Detector

Configure

  • /setraid <joins> <minutes> — e.g. /setraid 10 5
  • /raidstatus — show last-N-minutes joins vs threshold

Use it

It tracks recent joins in a rolling window. Helpful during hype/raids to decide when to moderate stricter.

FAQ / Troubleshooting

  • Bot doesn’t answer? In BotFather set Group Privacy = OFF. Make sure the bot isn’t muted/restricted. Try /help.
  • Too chatty? /set autochat off.
  • Raid buttons not counting? /raidtargets 0 0 0 → /raid → tap once → /raidprogress.
  • Invite link fails? Bot must be Admin with “Invite users via link”.
  • Undo a value? /unset <key> (e.g. /unset website). See all with /get.

Privacy & Data

  • Stored: per-group settings only (links, rules, welcome text, autochat, antibot + whitelist, raid mode/target/message, raid counters & goals, join-raid window, invite links/scores).
  • No personal data is stored or profiled.
  • Settings persist until an admin changes them or the group is removed.
