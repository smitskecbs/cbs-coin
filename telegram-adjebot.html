Adje Bot — Guide (@Adjecatbot)

Minimal, multi-group Telegram bot for links, welcomes, rules, GM streaks, and raids on X.
Quick nav: Quick Start Commands Raids Setup & Permissions BotFather Troubleshooting

Quick Start

  1. Add @Adjecatbot to your group. In busy groups, always address with mention, e.g. /links@Adjecatbot.
  2. Admins set links/text with /set <key> <value>. Keys: website telegram twitter/x discord instagram facebook mint ca topic welcome rules.
  3. Everyone can view: /links, or single keys like /website, /x, /welcome, /rules.

Commands

For everyone

  • /links – Show all configured links and notes.
  • /website /telegram /x (/twitter) /discord /instagram /facebook /mint /ca /topic – Show a single item.
  • /welcome, /rules – Show configured messages.
  • /gm, /streak – Good-morning streaks.

Admins only

  • /set <key> <value> – Set a link/text. For X use twitter or x. URLs must begin with http(s):// for link-keys.
  • /unset <key> – Remove a key.

Raid commands

  • /raid <x-url> [likes reposts replies] admin – Starts a raid and posts the live card in-chat.
  • /raid_status – Repost/refresh the current card.
  • /raid_add <likes|reposts|replies> N admin – Increment counts by N.
  • /raid_set <field> <value> admin – Set likes|reposts|replies or goal_* exactly.
  • /raid_end admin – End the raid (card stays as history).
  • /raid_refresh [x-url] – Pull live metrics once from X (Free plan friendly). Uses your server’s X_BEARER_TOKEN.

Raids – how it looks & flows

  1. Start: /raid https://x.com/handle/status/123... 50 30 20 → Adje posts a card with Likes | Reposts | Replies and goals.
  2. Update manually: /raid_add likes 5, /raid_set goal_reposts 40. The bot edits the same card.
  3. Live refresh from X: /raid_refresh (or /raid_refresh <url>) to fetch counters via X API once.
  4. Pin it: Pin the card for visibility. End with /raid_end when done.

Note: On X Free plan you have very few reads/month. Use /raid_refresh sparingly to avoid quota issues.

Setup & Permissions

  • Address Adje explicitly in crowded groups: /links@Adjecatbot, /raid@Adjecatbot ...
  • Admins are determined by either ADJE_ADMIN_IDS (server env) or your Telegram group role (administrator/creator).
  • To enable /raid_refresh: put your X Bearer token on the server as X_BEARER_TOKEN (no quotes). Then restart the service.

Troubleshooting

  • Another bot replies first? Use explicit mention: /links@Adjecatbot.
  • The raid card doesn’t appear? Start in the right chat and ensure you used a valid X URL (…/status/ID).
  • /raid_refresh says missing token? Put X_BEARER_TOKEN in your server env and restart.
  • Bot seems offline? DM @Adjecatbot with /start. On server: sudo systemctl status adje.
