English — How to use

Links & Info

Show everything with /links or use single commands:

/website   /telegram   /twitter or /x   /discord   /instagram   /facebook
/mint      /ca          /topic           /welcome    /rules

Streaks: /gm once per day increases your streak. Check with /streak.

Admins — setting values

Set a key per chat:

/set website https://example.com
/set x https://x.com/yourhandle
/set telegram https://t.me/yourgroup
/set mint https://solscan.io/token/YOUR_MINT
/set ca YOUR_SOLANA_MINT_ADDRESS  (base58, no https)
/set topic Layer-2, Airdrops, NFT, Staking
/set welcome Welcome aboard! Check /links, read /rules, claim /gm.
/set rules Be respectful | No spam/scams | No doxxing | No NSFW | DYOR

If another bot grabs /set, use /aset or mention the bot: /set@Adjecatbot … or /@Adjecatbot set …

Unset a key (fallback to defaults): /unset <key> (or /aunset)

Auto chat

Only reacts to slash triggers (no spam). Enable per chat:

/enable_auto
/autoreplies       (list)
/addreply lfg LFG! 🚀
/delreply lfg
/clearreplies
/disable_auto

Raids

Start or show a raid around an X post:

/raid https://x.com/handle/status/12345 50 30 20
/raid_status
/raid_add likes 5
/raid_set replies 10
/raid_end

Format shows progress like done | goal [xx%].

Troubleshooting

  • Other bot intercepts /set: use /aset or /set@Adjecatbot ….
  • Group privacy: auto triggers are slash-based, so privacy can be ON. For /@Adjecatbot … syntax, prefer /set@Adjecatbot ….
  • Twitter icon: bot shows X, no bird icon.
