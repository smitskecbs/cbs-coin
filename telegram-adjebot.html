Adje Bot – Handleiding / Guide

🇳🇱 Over Adje Bot

Adje Bot is een neutrale Telegram bot die in elke groep gebruikt kan worden. Functies:

  • Good Morning streaks (/gm, /streak)
  • Auto-chat met slash-triggers (aan/uit per groep)
  • Projectlinks opslaan per groep via /set (website, telegram, x, discord, instagram, facebook, mint, ca)
  • Raid tool met doelen en voortgang

Alle informatieve commando’s zijn voor iedereen; instellingen zijn admin only.

🇬🇧 About Adje Bot

Adje Bot is a neutral Telegram bot usable in any group. Features:

  • Good Morning streaks (/gm, /streak)
  • Auto-chat with slash triggers (per-group on/off)
  • Per-chat project links via /set (website, telegram, x, discord, instagram, facebook, mint, ca)
  • Raid tool with goals and progress

Info commands are open to all; settings are admin only.

🇳🇱 Commando’s voor iedereen

  • /start, /help – Uitleg
  • /gm – Claim je dagelijkse streak
  • /streak – Jouw streak + top 5
  • /links – Toon alle links (Website, Telegram, X, Discord, Instagram, Facebook, Mint, CA)

Losse info-commando’s

Toont enkel de gevraagde waarde:

/website /telegram /twitter /x /discord /instagram /facebook /mint /ca

Let op: voor Twitter wordt “X” gebruikt (geen vogeltje-icoon 😉).

🇬🇧 Commands for everyone

  • /start, /help – Help
  • /gm – Claim your daily streak
  • /streak – Your streak + top 5
  • /links – Show all links (Website, Telegram, X, Discord, Instagram, Facebook, Mint, CA)

Single info commands

Returns only the requested value:

/website /telegram /twitter /x /discord /instagram /facebook /mint /ca

Note: Twitter is shown as “X”.

🇳🇱 Admin-commando’s

Auto-chat

  • /enable_auto – Zet auto-chat aan
  • /disable_auto – Zet auto-chat uit

Links & adressen instellen (per groep)

  • /set website <url>, /set telegram <url>, /set twitter <url>, /set discord <url>, /set instagram <url>, /set facebook <url>
  • /set mint <adres>, /set ca <adres>
  • /unset <key> – Verwijder waarde (valt terug op standaard)

Tip wanneer een andere bot /set “pakt” (zoals Rose): gebruik /aset en /aunset, of richt je commando expliciet aan Adje: /set@JouwBotNaam ….

Geldige keys: website, telegram, twitter, discord, instagram, facebook, mint, ca.

🇬🇧 Admin commands

Auto-chat

  • /enable_auto – Enable auto-chat
  • /disable_auto – Disable auto-chat

Configure links & addresses (per chat)

  • /set website <url>, /set telegram <url>, /set twitter <url>, /set discord <url>, /set instagram <url>, /set facebook <url>
  • /set mint <address>, /set ca <address>
  • /unset <key> – Remove value (falls back to default)

If another bot intercepts /set, use /aset / /aunset, or address Adje directly: /set@YourBotName ….

Valid keys: website, telegram, twitter, discord, instagram, facebook, mint, ca.

🇳🇱 Raid functies

  • /raid <url> <likes> <retweets> <replies> – Start/overschrijf raid (admin). Zonder parameters toont hij de huidige status.
  • /raid_status – Toon voortgang
  • /raid_add <likes|retweets|replies> <n> – Tel erbij (admin)
  • /raid_set <likes|retweets|replies> <n> – Zet exacte waarde (admin)
  • /raid_end – Beëindig raid (admin)

Weergave bevat doelen, actuele aantallen en percentages, vergelijkbaar met jouw voorbeeld.

🇬🇧 Raid features

  • /raid <url> <likes> <retweets> <replies> – Start/overwrite raid (admin). With no params, shows current status.
  • /raid_status – Show progress
  • /raid_add <likes|retweets|replies> <n> – Increment (admin)
  • /raid_set <likes|retweets|replies> <n> – Set absolute value (admin)
  • /raid_end – End raid (admin)

Output shows goals, current counts, and percentages—styled like your sample.

ℹ️ Overige notities / Other notes

  • Als er geen waarde is ingesteld voor een key, gebruikt Adje de server-environment defaults (bijv. BOT_WEBSITE).
  • Data wordt lokaal opgeslagen in adje_state.json.
  • Werkt in privéchats en groepen. Admin-rechten zijn vereist voor instellingen.
  • Twitter wordt als “X” weergegeven; er wordt geen vogel-icoon gebruikt.
