Adje Bot – Gebruiks­handleiding / User Guide

Wat is Adje?

Adje is een neutrale Telegram-bot voor meerdere groepen. Hij geeft projectlinks en topics weer, kan een “gm”-streak bijhouden en eenvoudige raid-tellers tonen.

Tip: Geef Adje in je groep Can send messages en (optioneel) Delete messages voor stille modus.

Iedereen kan gebruiken

Snelle info

  • /links – alles in één overzicht.
  • /website, /telegram, /x (of /twitter), /discord, /instagram, /facebook, /mint, /ca
  • /topic of /topics – toont de topics als lijst.

GM & streaks

  • /gm – start of verlengt je streak.
  • /streak – jouw streak + top 5 in de chat.

Alleen voor admins / owners

Links & topics instellen

Standaard werkt /set (ja, dit werkt). In groepen waar een andere bot ook /set pakt, gebruik:

  • /aset … – veilige bypass (aanrader)
  • /set@Adjecatbot … – officiële vorm met mention
  • /@Adjecatbot set … – fallback die Adje ook begrijpt

Sleutels: website, telegram, twitter (X), discord, instagram, facebook, mint, ca, topic

/aset website https://smitskecbs.github.io/cbs-coin/
@Adjecatbot /set website https://…
/set@Adjecatbot topic Layer-2, Airdrops, NFT, Staking

Verwijderen: /unset <key> of /aunset <key>

Auto-chat

  • /enable_auto – eenvoudige slash-triggers aan
  • /disable_auto – uit

Raids

  • /raid <url> <likes> <retweets> <replies>
  • /raid_status
  • /raid_add likes 10, /raid_set retweets 50, /raid_end

Diagnostiek

  • /whoami – bot-username (voor mentions)
  • /chatid – huidige chat-ID

Belangrijke tips

Stille modus:

Als Adje delete-rechten heeft, verwijdert hij admin-commando’s en z’n bevestiging na een paar seconden. Controleer daarna direct met /website of /links.

Group privacy gewijzigd?

Verwijder Adje even uit de groep en voeg hem opnieuw toe, anders ontvangt hij soms geen berichten.

Beheer buiten de groep (server-instellingen)

Admin-whitelist (altijd admin)

Zet je Telegram-user-ID in het env-bestand (IDs via @userinfobot):

ADJE_ADMIN_IDS=123456789, 987654321

Daarna herstarten: sudo systemctl restart adje

Standaardlinks (optioneel)

Als een groep nog niets heeft ingesteld, gebruikt Adje deze env-defaults:

BOT_WEBSITE=…
BOT_TELEGRAM=…
BOT_TWITTER=…
BOT_DISCORD=…
BOT_INSTAGRAM=…
BOT_FACEBOOK=…
BOT_MINT=…

What is Adje?

Adje is a neutral Telegram bot usable across multiple groups. It shows project links & topics, tracks simple GM streaks, and provides a lightweight raid counter.

Tip: In your group, grant Adje Can send messages and (optional) Delete messages for low-noise mode.

Commands for everyone

Quick info

  • /links – all links in one message.
  • /website, /telegram, /x (or /twitter), /discord, /instagram, /facebook, /mint, /ca
  • /topic or /topics – list the topics nicely.

GM & streaks

  • /gm – start/continue your streak.
  • /streak – your streak + top 5 in the chat.

Admins / owners only

Set links & topics

By default /set works (yes, it works). If another bot also hooks /set, use:

  • /aset … – safe bypass (recommended)
  • /set@Adjecatbot … – official mention form
  • /@Adjecatbot set … – fallback Adje understands

Keys: website, telegram, twitter (X), discord, instagram, facebook, mint, ca, topic

/aset website https://smitskecbs.github.io/cbs-coin/
@Adjecatbot /set website https://…
/set@Adjecatbot topic Layer-2, Airdrops, NFT, Staking

Unset: /unset <key> or /aunset <key>

Auto-chat

  • /enable_auto – enable simple slash triggers
  • /disable_auto – disable

Raids

  • /raid <url> <likes> <retweets> <replies>
  • /raid_status
  • /raid_add likes 10, /raid_set retweets 50, /raid_end

Diagnostics

  • /whoami – bot username (for mentions)
  • /chatid – current chat ID

Important tips

Low-noise mode:

If Adje has delete rights, it removes admin commands and its own confirmations after a few seconds. Verify with /website or /links right away.

Changed group privacy?

Remove Adje from the group and add it again once to ensure it receives messages properly.

Out-of-group management (server)

Admin whitelist (always admin)

Put your Telegram user IDs in the env (IDs via @userinfobot):

ADJE_ADMIN_IDS=123456789 987654321

Then restart: sudo systemctl restart adje

Default links (optional)

If a chat hasn’t set links yet, Adje uses these env defaults:

BOT_WEBSITE=…
BOT_TELEGRAM=…
BOT_TWITTER=…
BOT_DISCORD=…
BOT_INSTAGRAM=…
BOT_FACEBOOK=…
