Adje Bot – Handleiding / Guide

🇳🇱 Over Adje Bot

Adje Bot is een neutrale Telegram bot die in elke groep gebruikt kan worden. Hij ondersteunt Good Morning streaks, een configureerbare auto-chat, en het opslaan van projectinformatie zoals Website, Telegram, Twitter/X, Mint en Contract Address (CA).

🇬🇧 About Adje Bot

Adje Bot is a neutral Telegram bot that can be used in any group. It supports Good Morning streaks, configurable auto-chat, and storing project information such as Website, Telegram, Twitter/X, Mint and Contract Address (CA).

🇳🇱 Beschikbare commando’s (iedereen)

  • /start – Uitleg en overzicht van functies
  • /help – Zelfde als /start
  • /gm – Claim je dagelijkse Good Morning streak
  • /streak – Bekijk je eigen streak + top 5 in de chat
  • /links – Toon ingestelde links (Website, Telegram, Twitter/X, Mint, CA)

🇬🇧 Available commands (everyone)

  • /start – Show help and overview of functions
  • /help – Same as /start
  • /gm – Claim your daily Good Morning streak
  • /streak – Show your streak + top 5 in the chat
  • /links – Display set links (Website, Telegram, Twitter/X, Mint, CA)

🇳🇱 Alleen voor admins

  • /enable_auto – Zet auto-chat aan in de groep
  • /disable_auto – Zet auto-chat uit in de groep
  • /set website https://voorbeeld.nl – Stel een website link in
  • /set telegram https://t.me/jouwgroep – Stel een Telegram link in
  • /set twitter https://x.com/jouwproject – Stel een X/Twitter link in
  • /set mint <adres> – Stel een Mint-adres in
  • /set ca <adres> – Stel een Contract Address in
  • /unset website – Verwijder de ingestelde waarde (valt terug op standaard)

🇬🇧 Admin only

  • /enable_auto – Enable auto-chat in the group
  • /disable_auto – Disable auto-chat in the group
  • /set website https://example.com – Set a website link
  • /set telegram https://t.me/yourgroup – Set a Telegram link
  • /set twitter https://x.com/yourproject – Set a Twitter/X link
  • /set mint <address> – Set a Mint address
  • /set ca <address> – Set a Contract Address
  • /unset website – Remove the set value (falls back to default)

🇳🇱 Auto-chat triggers

Als auto-chat is ingeschakeld, reageert Adje op deze commando’s:

  • /hello, /hi – Groet terug
  • /gm – Herinnering aan streak
  • /gn – Goede nacht wens
  • /wen – “When moon?”
  • /buy – DYOR advies
  • /rules – Groepsregels
  • /pump – Motivatie bericht
  • /helpme – Verwijzing naar /help

🇬🇧 Auto-chat triggers

When auto-chat is enabled, Adje responds to these slash words:

  • /hello, /hi – Friendly greeting
  • /gm – Streak reminder
  • /gn – Good night message
  • /wen – “When moon?”
  • /buy – DYOR reminder
  • /rules – Group rules
  • /pump – Motivational message
  • /helpme – Points to /help

⚙️ Notes

  • Per groep kunnen admins eigen links instellen.
  • Als er geen waarde is ingesteld, gebruikt Adje de standaard (environment variabelen).
  • Data wordt opgeslagen in adje_state.json op de server.
  • Adje werkt in privé chats en groepen.
