Adje Bot – Telegram Guide

About Adje Bot

Adje Bot is a neutral, multi-purpose Telegram bot. It can be added to any group or used in private chats. Features include daily good morning streaks, configurable auto-chat replies, and project info links.

Available Commands

  • /start – Show this help message
  • /help – Same as /start
  • /links – Show project links (Website, Telegram, X/Twitter)
  • /gm – Claim your daily Good Morning streak
  • /streak – Show your streak + top 5 in the chat

Admin Only Commands

Only admins in a group can use these:

  • /enable_auto – Enable auto-chat in the group
  • /disable_auto – Disable auto-chat in the group

Auto-chat Slash Triggers

When auto-chat is enabled in a group, Adje will respond to these slash words:

  • /hello – Friendly greeting
  • /hi – Simple “Hi” back
  • /gm – Reminder about Good Morning streak
  • /gn – Good night message
  • /wen – “When moon?” crypto joke
  • /buy – Reminder: Do Your Own Research
  • /rules – Group rules reminder
  • /pump – Motivational hype message
  • /helpme – Points to the /help command

Project Links

Configured by the bot owner via environment variables:

  • 🌐 Website → BOT_WEBSITE
  • 💬 Telegram → BOT_TELEGRAM
  • 🐦 X/Twitter → BOT_TWITTER

Example: in /etc/systemd/system/adje.service you can add: 

Environment=BOT_WEBSITE=https://example.com
Environment=BOT_TELEGRAM=https://t.me/example
Environment=BOT_TWITTER=https://x.com/example

Notes

  • Adje Bot works in both private chats and groups.
  • Only admins can change auto-chat settings in groups.
  • Everyone can use /gm, /streak, /links, /start, /help.
  • Data is saved in adje_state.json on the server.
